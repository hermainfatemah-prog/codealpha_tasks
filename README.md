# CodeAlpha Task 3 — Secure Coding Review

This repository section contains a Python/Flask security code-review exercise.

## Files
- `vulnerable_app.py` — intentionally insecure demo used as the review target.
- `secure_app.py` — remediated example showing safer coding patterns.
- `SECURITY_REVIEW.md` — findings, severity, evidence, remediation, and secure-coding recommendations.

## Review focus
SQL injection, credential handling, brute-force protection, data exposure, and production debug configuration.

See `SECURITY_REVIEW.md` for the complete review.
