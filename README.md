# CodeAlpha Phishing Awareness Training

## CodeAlpha Cyber Security Internship — Task 2

This project is a phishing awareness training presentation designed to educate users about phishing attacks, social engineering, suspicious emails and messages, fake websites, and safe response practices.

### Topics Covered
- What phishing is
- Common phishing warning signs
- Fake websites and suspicious URLs
- Social engineering tactics
- Real-world examples
- Prevention and best practices
- Interactive quiz and answer key
- What to do after clicking a suspicious link
- Key takeaways and reference resources

### File
- `CodeAlpha_PhishingAwarenessTraining.pptx`

### Objective
To help users recognize phishing attempts, verify unexpected requests, and respond safely to suspected phishing incidents.
